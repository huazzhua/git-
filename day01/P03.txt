git分支学习：git branch 分支名  --创建分支   git branch -v --查看分支   git checkout 分支名  --切换分支  git merge 分支名 --合并分支   注意当指针在分支路径上是，对文件进行的修改都会保存在分支上，与master路径无关，若想将修改的结果返回到master路径上必须使用合并路径


注意，当你git branch 分支名 创建分支时，是拷贝当前路径的最新版本


注意：当你使用git merge合并操作时，要注意指针立场，如果当前指针指向master,则就是将其他分支合并到master上，反之如果指针当前指向分支，合并就是将master合并到分支上
